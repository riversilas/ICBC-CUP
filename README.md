# 绿碳链证

让数据有来源，让记录可追溯，让核对有依据。

本地运行的电力企业碳数据演示工具：查看原始数据与跨期变化、保存补充材料、生成带版本的报告，并核对提交的登记材料。**现行页面不计算综合表现分，不提供等级、授信结论或利率建议。**

## 快速启动
需要 Python 3.10+，依赖仅 FastAPI 与 Uvicorn。先完整解压到可读写目录，不要只下载一个文件。

- Windows：双击 `启动.bat`。脚本检查虚拟环境是否可执行；失效环境改名保留并重建，缺依赖或清单改变时联网安装。
- macOS：在项目根目录终端执行 `bash start.command`，首次创建本机虚拟环境并安装依赖。
- 手动：`python -m pip install -r requirements.txt`，再运行 `python app.py --port 8910`。
- 访问：<http://127.0.0.1:8910/>。保持终端开启，按 Control+C 停止。

不打包 `.venv`、`.venv-*`、`__pycache__`、本机数据库、操作账本及历史压缩包。Mac 不能运行 Windows 的 exe、bat 或虚拟环境。端口占用时仅处理本项目监听进程，或手动改为 `--port 8912`。详细排障见 [Mac说明](docs/MACOS_GUIDANCE.md)。

## 四步体验
1. **选企业**：可以从大唐发电示例开始，也可按名称/代码选择其他企业。
2. **读碳画像**：先读年度、数据性质与原值，再看同比；四轴变化图显示直接排放、间接排放、发电量和排放强度，以前期为100。面积不是好坏评分，也不能据此比较不同企业绝对强度。
3. **生成报告**：确认材料后生成版本化登记包，打印报告或下载JSON。报告三轴图仅展示直接排放、间接排放和发电量；总量、强度另列，避免派生指标重复占轴。
4. **核验材料**：输入登记摘要并提交对应JSON材料，区分材料匹配、登记状态、链内部一致性和当前/历史版本。仅查询摘要不等于验证用户手里的文件。

详见 [图文使用指南](docs/USER_GUIDE.md)。

## 能做什么、不能证明什么
- 可复算排放强度，展示数据来源与同口径比较条件；缺失值保持缺失，不编造数据。
- 环保投入不等于已核实转型资本开支；清洁装机比例不等于清洁发电比例。
- 输入含演示/未独立核验附件数据，不是原报告真实性认证。
- 本地哈希链验证内部一致性，不是独立区块链共识，不抵御控制整本账本后重算或删尾。
- 用户补充和银行材料只是记录，不构成专业鉴证、自动审批或投资建议。

## 当前流程与历史算法的边界
当前前端使用原始碳画像与登记材料，不调用历史 `main-quant` 评分展示。为兼容历史研究与已有接口，`carbon_model.py`、`engine.py` 和 `/api/main-quant` 仍保留旧算法；其中等级、权重和定价输出不属于现行产品结论。历史算法版本与现行应用版本是不同概念，不改写历史凭证中的方法标识。旧的 `docs/data-report/` 是历史导出，不应视为本次修订后的使用入口。

## 保存的数据
披露输入在 `data/`；附件快照在 `data/processed/radar_attachment_snapshot.json`。本机账本与用户补充数据库位于 `data/processed/`，默认不提交到GitHub；操作前请备份。历史根目录账本与旧兼容页面保留作历史用途，不以当前新界面回写。
