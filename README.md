# ICBC-CUP-GreenTrace

给电力企业做碳画像的本地工具：排放、发电、投入这些数字，从年报和 ESG 报告里整理出来，算得清、讲得明，交出去的每份报告都能回头核对。

## 它解决什么问题

银行做绿色信贷时常见三个麻烦：企业披露散落在年报和 ESG 报告里，读完不好讲；补充材料交来交去，说不清用的是哪一版；手里有碳数据，却不知道从哪个问题问起。

这个工具把这三件事串起来：数据集中在一张画像上，材料改动留下版本记录，报表和图形给出可以直接问出口的问题。结果是否真实、项目是否绿色、贷款批不批，仍然由人工和银行流程判断——工具不替你做结论。

## 快速开始

需要 Python 3.10 以上，依赖只有 FastAPI 和 Uvicorn。把仓库完整下载到本地可写目录。

- Windows：双击 `启动.bat`，按提示等待依赖安装完成。
- macOS：在项目根目录执行 `bash start.command`。
- 手动：`python -m pip install -r requirements.txt`，然后 `python app.py --port 8910`。

浏览器打开 <http://127.0.0.1:8910/>，用完在终端按 Ctrl+C 停止。

不要把别的电脑的 `.venv` 拷过来，Mac 跑不了 Windows 的 bat 和 exe。端口被占用就换个端口，别去杀所有 Python 进程。更多排障见 [Mac说明](docs/MACOS_GUIDANCE.md)。

## 走一遍流程

1. **选企业**：点"开始示例 · 大唐发电"，或从卡片里挑一家。先看年度和数据性质，再读数字。
2. **看画像**：排放、发电、强度的原值和同比都在这里。变化图以前一期为 100，图形面积不代表好坏，也不用来比较两家企业。
3. **补材料、出报告**：有项目资料就填进"数据复核 / 补充"，预览后保存；再到第三步生成参考报告，可打印也可下载 JSON 登记包。
4. **核对材料**：拿登记摘要查记录，上传 JSON 比对，看材料和当时登记的是否一致。摘要查得到，只说明有这条记录，不等于验证了你手里的文件。

具体字段怎么填、图怎么读，见 [使用手册](docs/USER_GUIDE.md)。

## 数据从哪来

三家电力上市公司的公开披露：年报、ESG／可持续发展报告和现金流量表，取排放量、发电量、环保投入和清洁装机这些字段。附件快照在 `data/processed/radar_attachment_snapshot.json`，来源标题随数据一起记录；另有五家演示数据，单独标注，不混进附件组。

抓来的数字不代表已经核实过原文。组织边界、气体口径和 Scope 2 方法要对照原报告确认；环保投入不等于低碳转型资本开支，清洁装机占比也不是发电占比。

## 边界

- 本页不计算综合分、等级或利率建议；历史评分代码保留仅为兼容，不作为现行产品结论。
- 报告登记在本机哈希链上，只保证内部一致。它防不住拿到整本账本的人重算，也不是公共区块链。
- 材料比对结果"一致"，意思是提交的 JSON 和登记版本相同，不是原始数据真实性的证明。
- 用户补充和银行相关记录只是待核信息，不构成鉴证或审批意见。
