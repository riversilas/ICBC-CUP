# 绿鉴 · 电力企业碳表现量化模型 V3.0（PCPS 简化版）

> **PCPS** = Power Carbon Performance Score
> 三维度：强度（存量水平）· 趋势（转型速度）· 结构（未来有多绿）
>
> 定位：工行杯参赛作品的量化模块。核心创新点是**区块链存证与多方查验**，
> 本模块只负责把公开披露数据折成一个可比较、可复算、可上链的数值。

---

## 一、为什么从 V2.0 改到 V3.0（一个真实的 bug）

V2.0 的强度公式是 `S₁ = min(100, 100 × (2 − CI ÷ 基准线))`，**封顶 100**。
后果：任何优于煤电基准线（820 gCO₂/kWh）的企业都拿满分。实测中
**大唐发电（739.7）和国投电力（287.7）同为 100 分**——一个火电为主、
一个清洁能源占 70%，模型却给出相同的分数，区分度完全丧失。

V3.0 改用固定标尺归一化，保住梯度：`S_强度 = 100 × (900 − I) ÷ 900`。
同两家企业现在分别是 **17.8 分** 与 **68.0 分**，差距被正确区分出来。

## 二、三大维度公式（PPT 一页即可）

### 维度一：静态度电碳排放强度 S_强度（权重 40%）

```
I =（范围一 + 范围二）÷ 全口径发电量          单位 gCO₂/kWh
  ※ tCO₂/GWh 数值上恰好等于 gCO₂/kWh（1 t = 10⁶ g，1 GWh = 10⁶ kWh）

S_强度 = 100 × (900 − I) ÷ 900                限定 [0, 100]
```

标尺：`I_min = 0`（完全清洁，满分）、`I_max = 900 gCO₂/kWh`（低效煤电，0 分）。
全国碳市场煤电基准线约 820 gCO₂/kWh，对应强度项约 **9 分**。

### 维度二：动态减排趋势 S_趋势（权重 35%）

```
τ =（I_今年 − I_去年）÷ I_去年 × 100%         正 = 反弹，负 = 减排

S_趋势 = 50 + 50 × tanh(−5 × τ)               自然收敛于 [0, 100]
```

`tanh` 的价值：减排再猛也不爆表，反弹再大也不出负分，两端平滑。

| 情形 | τ | S_趋势 |
|---|---|---|
| 强度持平 | 0% | 50.0 |
| 同比减排 5% | −5% | 62.2 |
| 同比减排 20% | −20% | 88.1 |
| 同比反弹 7% | +7% | 33.2 |
| 同比反弹 20% | +20% | 11.9 |

> **k 的取值说明**：原方案建议 `k = 15`（此时 +7% 反弹只用 11 分）。但实测发现
> k=15 太灵敏——火电企业年度强度变化普遍在 ±3% 以内，k=15 会把正常波动放大成
> 极端分数（大唐仅 +3.23% 就被压到 6 分）。**本模型取 k = 5**，让 ±5% 的年度变化
> 对应约 12 分的分差，更贴合电力行业的实际波动幅度。k 属待校准参数，需做敏感性测试。

### 维度三：清洁能源结构渗透率 S_结构（权重 25%）

```
ρ =（风电 + 光伏 + 水电 + 核电）发电量 ÷ 总发电量

S_结构 = 100 × ρ^0.8                          幂次 < 1，前期边际激励最大
```

### 合成

```
碳表现分 S = 0.40 × S_强度 + 0.35 × S_趋势 + 0.25 × S_结构
```

### 全绿豁免

```
若 I ≤ 50 gCO₂/kWh（天然近零碳，如纯水电）：
    S = max(S, 95)     避免"已达零碳、无从改善"在趋势项上被无谓扣分
```

## 三、为了"能真算出来"做的四处简化（答辩要能讲清）

原方案（Gemini 版）设计得很好，但有几个量在我们的公开数据源里取不到。
以下四处简化**不改变大体逻辑**，只把无法获取的输入替换为可获取的等价量：

| 原设计 | 问题 | V3.0 处理 | 影响 |
|---|---|---|---|
| 趋势用**同比**变化率 | 单年波动大（大唐 2024 同比 +3.23%，但三年年化是 −0.80%，方向都反了） | 优先同比；有三年数据时改用**多年度等效年化变化率** | 更稳健，且口径在界面上标注 |
| 结构用**发电量口径**占比 | 部分企业只披露**装机占比**，不披露分品种发电量 | 发电量口径优先，缺失时退回装机占比，**并标注用的是哪种口径** | 保住维度可得性，代价是口径不齐（界面明示） |
| 缺失维度计 0 分 | 会把"没披露"误判成"表现差" | 权重**重新归一化**到剩余可得维度，不臆测、不计 0 | 避免冤枉未披露企业 |
| 全绿豁免写死"锁定 95 分以上" | 纯水电企业没有排放数据，无法计算 | 改用**强度门槛触发**（I ≤ 50） | 逻辑等价，但可复算、可审计 |

## 四、实测验算（真实公开数据）

数据来源：各公司 2024 年度报告 / ESG 报告，强度按统一口径复算。

| 企业 | 排放强度 | 同比变化 | 清洁占比 | S_强度 | S_趋势 | S_结构 | **综合** | 评级 | Δr |
|---|---|---|---|---|---|---|---|---|---|
| 国投电力 | 287.7 | −8.49% | 67.2% | 68.0 | 70.0 | 72.8 | **69.9** | B+ | −10 BP |

| 浙能电力 | 872.7 | +0.30% | 未披露 | 3.0 | 49.2 | 缺失 | **24.6** | C | +35 BP |
| 华能国际 | 拒披 | — | — | — | — | — | 数据不足 | 无法评级 | — |
| 国电电力 / 华电国际 / 上海电力 / 长江电力 | 待补 | — | — | — | — | — | 数据不足 | 无法评级 | — |

**模型行为符合预期**：国投电力清洁占比 67.2% 且强度在降，拿 B+；

## 六、数据可信度（与碳表现分完全分离）

| 等级 | 判定 |
|---|---|
| A | 三年数据完整 + 有清洁占比 + 第三方鉴证 |
| B | 三年数据完整 + 有清洁占比 |
| C | 至少两年数据 |
| D | 仅一年或数据不足（**长江电力属此类，但其强度天然近零，触发全绿豁免**） |

**可信度不折算进碳表现分**，避免"花钱做鉴证就能提分"的错误激励。

## 七、上链字段

存证的不是一个分数，而是**"哪套数据、哪版模型、哪版标尺"共同产生了这个分数**，
使任何人都能独立复算并验证链上摘要。

| 字段 | 含义 |
|---|---|
| `code` / `name` / `group` / `year` | 企业标识与报告年度 |
| `ci_g_per_kwh` | 度电碳排放强度（复算值） |
| `change_rate_pct` / `change_rate_basis` | 变化率与所用口径 |
| `clean_energy_share_pct` / `_basis` | 清洁占比与口径（发电量 / 装机） |
| `score_intensity` / `score_trend` / `score_structure` | 三维度子分 |
| `weights_applied` | **实际生效的权重**（缺失维度后归一化的结果） |
| `carbon_score` / `rating` | 综合分与评级 |
| `data_coverage` / `confidence_grade` | 数据覆盖度与可信度 |
| `model_version` / `baseline_version` | 模型与标尺版本 |
| `timestamp` | 计算时间 |

`digest = SHA256(规范化 JSON(payload))`，链上只存 digest + 版本号 + 时间戳。
模型升级生成**新版本凭证，不覆盖旧凭证**——保证历史可追溯。

## 八、已知局限（主动讲，比被问出来好）

1. **口径不可比问题**：企业自报"排放强度"多以火电发电量为分母（大唐自报 853.83，
   统一口径复算 739.7，差 15.4%），平台统一改用全口径发电量。**这是刻意的偏离，
   不是错误**，界面上明示差异。
2. **清洁占比口径不齐**：部分企业用发电量、部分用装机，界面标注所采用口径。
3. **样本量小**：8 家、最多三年。分数只适合样本内相对比较，不能外推为行业绝对评级。
4. **`tanh` 系数 k=5 是经验值**，应做敏感性测试（k=3 / 5 / 8）验证排序稳定性。
5. **全绿豁免的门槛（50 gCO₂/kWh）与保底分（95）均为待校准参数**。
6. **拒披企业无法评分**：华能国际以"商业秘密"为由未披露 2024 年碳排放。
   这不是模型缺陷，而是真实世界的数据缺口——恰好证明"可验证披露 + 存证"有需求。
